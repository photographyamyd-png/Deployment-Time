5) Motif System (Doc 3)

  • Group A: Structural sweeps/transitions (A1-A6)
  • Group B: Corner/panel motifs (B1-B5)
  • Group C: Watermark planes (C1-C3)
  • Group D: Micro UI motifs (D1-D7)
Canonical slot mappings: .motif-corner, .motif-slash, .motif-cross, .motif-triangle remain the primary service-panel motif attachment points.

6) Hard Rules

  • Single primary accent token: --yellow-core
  • No duplicate owner definitions for the same section ID
  • One animated watermark/sweep per page maximum
  • Watermark opacity range target: 0.025 to 0.10 maximum
  • Prefer section-prefixed class families (st3__, ab3__, why3__, etc.)
